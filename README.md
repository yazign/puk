# Какой я пердёж

Шуточное Android-приложение: фотографируешь лицо и узнаёшь, какой ты пердёж.

## Как получить APK
1. Загрузите все файлы этого архива в новый репозиторий GitHub (вместе с папкой `.github`).
2. Откройте вкладку **Actions**: сборка «Build APK» запустится сама (или нажмите **Run workflow**).
3. Через 5–7 минут откройте завершённую сборку и скачайте **KakoyYaPerdezh-apk** внизу страницы.
4. Распакуйте zip, перекиньте `KakoyYaPerdezh.apk` на телефон и установите (разрешите установку из неизвестных источников).

## Где что менять
- Звуки: `app/src/main/res/raw/fart_01.mp3` … `fart_10.mp3` (01 — самое весёлое лицо, 10 — самое грустное).
- Названия и описания звуков: `app/src/main/res/values-ru/strings.xml` (русский) и `values/strings.xml` (английский).
- Цвета: `app/src/main/res/values/colors.xml`.
- Логика выбора звука: функция `pickSound` в `MainActivity.kt`.
